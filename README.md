# ARY & MAZ Developments — Smart Calculator Engine

An elegant, high-performance, single-page Sales & Pricing Calculator Engine built from scratch for ARY & MAZ Developments in Dubai. 

## 🚀 Key Modules
1. **Unit Price Breakdown (Module 1):** Dynamic inputs and sliders (Discount, DLD, Admin Fee, Down Payment, Pre/Post Splits) with real-time recalculations.
2. **Batch Purchase (Module 2):** Add and aggregate financial metrics for up to 15 units.
3. **Discount Impact (Module 3):** Role-aware margin authority check (Sales Agent, Senior Agent, Manager, CEO) with instant WhatsApp sharing.
4. **Inventory Dashboard (Module 4):** Real-time metrics on sold ratio, pipeline, total value, and project appreciation.

## 📄 Custom PDF/Paper Exports
Includes a premium **Printable Offer Letter** layout for clients, formatted clean of user-interface controls.

## 🛠 Tech Stack
- **Framework:** Next.js (App Router)
- **State Management:** React Hooks (`useReducer`, `useState`, `useMemo`)
- **Styling:** Custom Vanilla CSS (Minimalist Luxury Aesthetic)
- **Data Source:** Runtime parsed `inventory.csv`

## 📦 Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
